### d999459d964d · root-cause · Hop Caddyfile has no derio.net vhost, so Caddy holds no apex cert

clusters/hop/apps/caddy/manifests/files/Caddyfile defines www.derio.net but not derio.net. Caddy only issues certs for named site addresses, so an apex SNI handshake fails with internal_error and Cloudflare (proxied) reports 525. Caddy issues via acme_dns cloudflare (DNS-01), so adding the vhost yields a valid cert regardless of the record being proxied; no DNS change is required for the fix. Issue item 3 (handle_errors re-import) is already on main; item 2 (real www image) is live state, outside this repo change.
